================================================================
Copy the folders in this zip over C:\Users\Bareenmakhdoomi\Desktop\pivot-app (replace files), then in that folder:

1. Delete the old placeholder UI files:
     del src\client\app.tsx src\client\app.css src\client\main.tsx
2. npm install            (React is no longer used – the workspace is plain JavaScript)
3. npm run build
4. npm run deploy         ("Forbidden" while tracking is OK – check the tracker link)

   git commit -m "PIV-063 Concept 27 workspace on real tables, REST API, business rules"
   git push
